## Fixes

- **pi 1.6.0 compatibility for `toolStyle: "claudecode"`.** Clicking a folded tool group did not expand the tool on pi 1.6.0. pi-tui 1.6 routes `Container` mouse events through a new `childLines` layout, and the grouped render only wrote the older `mouseLayout`, so clicks landed on the ungrouped children and the host re-rendered them to rebuild the layout. The grouped render now writes both, so pi 1.5 and 1.6 both work.
- The prompt editor copies `Editor.render()` output before patching the prompt and border rows, since pi-tui 1.6 allows components to return a cached render array.
